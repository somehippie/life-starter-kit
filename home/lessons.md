# Home: lessons

| Lesson | Why it tends to hold | How to apply it |
|---|---|---|
| Change the consumable before the hardware | The soap, filter or cartridge is usually what decides the result, and it is the cheapest part | Before replacing a device, try the better consumable in the one you have |
| Pilot one unit before buying for the whole house | Problems such as a soap that dispenses badly in a given pump only show up in use | Buy one, put it where it gets the most use, and decide after a few weeks |
| Put the trial where use is heaviest | It reaches a verdict fastest | Busiest sink, most-used room |
| Anchor recurring upkeep to one date | "When did I last do this?" becomes a calculation, not a guess | Write down the install date and count every schedule from it |
| Put upkeep on a calendar on day one | Weekly, monthly and quarterly tasks are easy to forget individually | Create recurring events for every task as soon as the equipment arrives |
| Match the test kit to the system | A kit built for one sanitizer can misread another, making good water look bad | Use the strips your sanitizer's manual names |
| Check what a basic kit does not measure | Cheap kits often skip alkalinity, which is the first thing to adjust | Read the kit's label against the readings your manual asks for |
