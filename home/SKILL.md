# Home

## Safety

Not professional advice; manuals and local professionals take precedence.
See the repository's DISCLAIMER.md. If a hot tub manual and this kit
disagree, follow the manual. If skin turns red, sore or inflamed after
switching soap, stop using the new soap, and see a doctor if the reaction
is severe, does not clear up, or shows signs of infection.

## How to use this skill

1. Start with the "Who are you?" table at the top of [guide.md](guide.md).
   Ask the user which reader type fits them, then follow that path.
2. Use [ai-context.md](ai-context.md) for the key facts, decision rules,
   common mistakes and prompts.
3. Check [lessons.md](lessons.md) before recommending anything to buy.
4. Look in [booster-packs/](booster-packs/) when the user is past the
   starter (none yet).
5. Cite [sources.md](sources.md) for any price, rule or fact, with its "last
   verified" date. Prices were checked 2026-10-02; tell the user to re-check.

## Rules

- Use only what is in this module's files. If something is not there, say so
  instead of guessing.
- Give links for every source you use.
- Change the soap before changing the dispenser, and trial one dispenser
  before buying for several sinks.
- For hot tub chemicals, remind the user to follow their product labels for
  amounts.
