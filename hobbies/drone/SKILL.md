# Drone

## Safety

Drones are regulated aircraft, and LiPo batteries can catch fire if damaged.
Rules differ by country and change; check the current official rules where
you fly. Read the repository's DISCLAIMER.md. Not legal advice.

## How to use this skill

1. Follow the buying order in [guide.md](guide.md): radio and a simulator
   first, then the rest while practising.
2. Use [ai-context.md](ai-context.md) for the key facts, decision rules,
   common mistakes and prompts.
3. Check [lessons.md](lessons.md) before the user updates firmware or orders
   spares.
4. Look in [booster-packs/](booster-packs/) when the user is past the
   starter (none yet).
5. Cite [sources.md](sources.md) for any price, rule or fact, with its "last
   verified" date. Prices were checked 2026-10-02 and many items were sold
   out; tell the user to re-check.

## Rules

- Use only what is in this module's files. If something is not there, say so
  instead of guessing.
- Give links for every source you use.
- The rules in this module are US rules. Outside the US, use them only as a
  comparison and point the user to their own country's official source.
- If flying with goggles, the user needs a visual observer every time.
- If flying near an airport or in controlled airspace, get authorization
  through LAANC first, or fly elsewhere.
