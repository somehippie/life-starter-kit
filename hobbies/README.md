# Hobbies: skills that lead to flow state

A hobby worth starting is one you can get lost in. Each kit here is a path
into flow state: the point where a skill is hard enough to hold all your
attention and practised enough that it stops feeling like effort. The kits
cover what to buy, in what order, and how to get through the awkward first
weeks quickly, so you reach that point sooner.

Art and music will join later.

| Hobby | What it covers | Status |
|---|---|---|
| [Drone](drone/) | Getting into FPV flying: what to buy, in what order, and the rules for recreational pilots | Draft |
| [Motorsports](motorsports/) | A map of the ways to ride and drive for fun, from track days to e-scooters | Planned |
| [Snowboarding](snowboarding/) | Gear, style and getting through the first days on snow | Planned |
| [Skateboarding](skateboarding/) | Gear, style and learning the basics | Planned |
| [Photography](photography/) | Gear and a way of seeing | Planned |
| [Fishing and boating](fishing-boating/) | Getting started on the water | Planned |
