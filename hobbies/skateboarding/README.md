# Skateboarding

> **Safety note:** skateboarding carries a real risk of falls and injury.
> Wear a helmet and pads while learning, and skate where it is allowed. Read
> [DISCLAIMER.md](../../DISCLAIMER.md).

**Status:** Planned. Scope only; no guide yet.

**Who it is for:** someone who wants to start skating, or come back to it,
and wants a setup and a style that suit them.

**Reader types:**

- **Curious but unsure:** wants to try it cheaply before committing.
- **Ready to buy a setup:** wants to know which board, trucks and wheels to
  start with and why.

## Scope

The owner's own style, perspective and gear recommendations, written up
from interviews and checked against dated sources.
