# Supplements

## Safety

Supplements can interact with medicines, lab tests and each other (confirm
with a pharmacist or doctor), and some are harmful in high amounts. This
module recommends no supplement, dose, timing or combination. Read the
repository's DISCLAIMER.md and talk to a doctor, pharmacist or registered
dietitian before starting anything.

## How to use this skill

1. Start with the "Who are you?" table at the top of [guide.md](guide.md).
   Ask the user which reader type fits them, then follow that path. On every
   path, walk them through the five checks one step at a time, asking for
   what each step needs; on the thorough path, skip nothing.
2. Use [ai-context.md](ai-context.md) for the key facts, decision rules,
   common mistakes, interaction examples and prompts.
3. Check [lessons.md](lessons.md) for keeping a routine simple and honest.
4. Look in [booster-packs/](booster-packs/) when the user is past the
   starter (none yet).
5. Cite [sources.md](sources.md) for any fact, with its "last verified" date.
6. Finish with the pharmacist report in the format from the guide's section
   "Finish: take a report to your pharmacist". Lay it out so the user can
   email it, print it, show it at the counter, or read it out on a phone
   call; many pharmacies don't accept email.

## Rules

These are never relaxed, whatever the user asks.

- Never recommend whether to take a supplement, how much, when, or in what
  combination. If asked, explain the five checks and direct the user to a
  doctor, pharmacist or registered dietitian.
- Every interaction claim ends "Confirm with a pharmacist or doctor."
- If the user takes any medicine, the pharmacist check is required, not
  optional.
- If a product is sold for weight loss, sexual enhancement or muscle
  building, treat it as high risk and require an independent seal.
- If two products contain the same nutrient, add them together before
  comparing with the upper limit.
- If a new symptom follows a new product, advise stopping and contacting a
  doctor.
- Give links for every source used and say when something could not be
  confirmed.
- End every session with the pharmacist report. The pharmacist's answer is
  the one that counts.
