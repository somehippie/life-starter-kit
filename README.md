# Life Starter Kit

Practical starter kits for parts of everyday life: what to buy, in what order,
what it costs, and what tends to go wrong. Each kit is written from real
experience, generalized so anyone can use it, and checked against dated
sources.

**Not professional advice.** Read [DISCLAIMER.md](DISCLAIMER.md) before acting
on anything here, especially the health and safety modules.

## How to use it

1. Pick a module below and open its README. It says who the kit is for and where to start.
2. Follow `guide.md`. It starts with "Who are you?": pick the reader type that fits you and follow its path through the steps, with budget, mid and upgrade tiers.
3. Read `lessons.md` for what tends to work and what does not.
4. Want it tailored to you? Paste the module's `ai-context.md` into any AI assistant and use the prompts at the end of it.
5. Using Claude? Load the module's `SKILL.md` as a skill instead; its README says how.
6. Check `sources.md` before buying. Prices and models change; every fact there has a "last verified" date.

Each module is a **starter kit** for first-time users. **Booster Packs**, in
each module's `booster-packs/` folder, take you further once the starter is
solid.

## Other languages

English is the canonical version. To read a module in another language, see
[TRANSLATE.md](TRANSLATE.md) for a prompt that translates it with any AI, or
check [translations/](translations/README.md) for reviewed translations.
Contributing one? The rules are in TRANSLATE.md.
